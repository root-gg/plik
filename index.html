PlikTemporary File Upload System

A scalable & friendly temporary file sharing platform — like WeTransfer, self-hosted.

Documentation
View on GitHub
🚀

Powerful CLI

Cross-platform Go client with archive, encryption, and auto-update support.

🌐

Modern Web UI

Clean Vue 3 interface for uploading, downloading, and managing files.

💾

Multiple Backends

File, S3, OpenStack Swift, Google Cloud Storage for data. SQLite, PostgreSQL, MySQL for metadata.

🔒

Security First

Password protection, OneShot downloads, end-to-end encryption (age), XSRF protection.

🔑

Flexible Authentication

Local accounts, Google, OVH, and OpenID Connect (OIDC) providers.

⚡

Stream Mode

Stream files directly from uploader to downloader — nothing stored on the server.
